# Tasks

## 1. Хранение и сохранение даты

- [x] 1.1 Написать тест миграции на прежнем контакте и увидеть падение. Добавить в схему Drizzle поля `birth_day`, `birth_month`, `birth_year` и ограничение допустимых сочетаний, сгенерировать миграцию и убедиться, что тест подтверждает NULL у прежнего контакта и сохранность его данных.
- [x] 1.2 Написать тесты серверного разбора формы для трёх допустимых вариантов, неполной пары «день и месяц», невозможных дат и 29 февраля с годом и без него. Увидеть падение тестов на новом поле, реализовать проверку и добиться зелёного прогона.
- [x] 1.3 Тестами действий на настоящей БД проверить создание, добавление и удаление только года, очистку всей даты, отсутствие поля у старого клиента, чужой контакт и конфликт версий. После красного прогона подключить дату к существующим действиям и повторить тесты до успеха.

## 2. Карточка контакта

- [x] 2.1 Написать отдельные Playwright-тесты для сценариев «Дата неизвестна», «День и месяц без года» и «Дата известна». После красного прогона добавить подписанное поле в общую форму и показ даты в карточке. Проверить все три теста после повторного открытия карточки.
- [x] 2.2 Проверить редактирование ранее созданного контакта с пустой датой. Добавить отдельные браузерные проверки для исправления даты, изменения только года и очистки, запустить их до изменения формы, затем довести сохранение и повторное открытие до зелёного результата. Проверку исчезновения строки на главной завершить в задаче 4.2.

## 3. Выборка дней рождения

- [x] 3.1 Написать отдельный тест БД для каждого календарного сценария спецификации с фиксированным временем. Увидеть падение, реализовать семидневную выборку, проверить московскую полночь, обе границы окна, переход года и оба варианта февраля для дат с годом и без него.
- [x] 3.2 Добавить отдельные тесты на изоляцию владельцев и исключение удалённых и пустых записей, на контакт за пределами первой сотни и на порядок при разных и совпадающих датах. После красного прогона добавить условия и сортировку. Проверить точный состав и порядок строк.

## 4. Блок на главной

- [x] 4.1 Написать отдельные Playwright-тесты для перехода в карточку, пустой недели и видимости при поиске или выборе группы. Проверить красный прогон на заполненной книге, встроить блок между «Пора связаться» и алфавитным списком, добиться прохождения тестов.
- [x] 4.2 Завершить сквозной тест «Исправление и очистка». На каждый сценарий из спецификации должен приходиться отдельный тест. Проверить, что исправление даты меняет порядок строк после сохранения, а очистка поля убирает контакт из блока.
- [x] 4.3 Запустить штатные проверки формата, линтера, типов, Vitest и Playwright. Проверить, что одновременно видны оба блока с напоминаниями, а алфавитный список сохраняет свой порядок.
