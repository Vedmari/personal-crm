# Design

## Context

Список на главной сгруппирован по буквам (`groupByLetter` в `contact-list.tsx`, буква — `getGroupLetter`), показывается порциями по 100, длина в адресе `?shown=`. Порядок — `name collate "ru-x-icu"`, затем `id`.

## Decisions

### 1. Запрос: первое место каждой буквы

`listLetters(search, groupId)` берёт имена всех подходящих людей в порядке списка (только `name`, без остальных полей) и в JS проходит их один раз: буква — через тот же `getGroupLetter`, место — номер строки. Так буквы вырубок совпадают с буквами списка («Ё» вместе с «Е», не-буквы — «#»), а порядок — с порядком списка. На тысячу контактов это около 20 КБ из базы на рендер, в браузер уходят только буквы и места.

Альтернатива — считать букву в SQL: пришлось бы повторить правила `getGroupLetter` и ICU в двух местах. Отклонено.

### 2. Вырубка — обычная ссылка с якорем

Вырубка — `<Link replace scroll={false}>` на `listHref({ q, group, shown })` с якорем `#letter-<буква>`, где `shown = max(текущая длина, shownFor(место))`. У секции буквы `id="letter-<буква>"` и `scroll-margin-top` на высоту строки поиска. Без JavaScript ссылка тоже работает: якорь ведёт браузер к букве. `replace` держит переход вне истории, длина списка в адресе даёт «Назад» из карточки на то же место.

Прокрутку к якорю силами Next.js проверка отклонила: в одном прогоне из четырёх список догружался, а к букве не прокручивал. Next прокручивает в момент перехода, а нужная секция появляется позже. При нажатии до гидратации браузер ищет якорь, пока список ещё приходит потоком. Поэтому у ссылки `scroll={false}`, а прокручивает `revealLetter` (`src/lib/reveal-contact.ts`). Она ждёт появления видимой секции, как `revealContact` ждёт строку нового контакта. Адрес с буквой при загрузке страницы обрабатывает так же `LetterFromAddress`.

### 3. Где висят вырубки

Колонка вырубок — `sticky` у правого края листа, сверху под строкой поиска. На компьютере (`md`) каждая вырубка — бумажный язычок цвета `paper-aged`, выступает за край листа на сукно. На телефоне — полоска букв шириной 16 px внутри листа у самого края, правее рукописных букв списка. Колонка начинается у заголовка (`--tabs-top`), высота вырубки — `min(24–28 px, (окно − --tabs-top) / число букв)`: вся колонка помещается в окно с самого начала.
