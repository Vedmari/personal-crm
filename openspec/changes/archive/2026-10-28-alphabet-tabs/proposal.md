# Proposal

## Why

Список показывает контакты по 100, и до человека на «Я» в книге из тысячи приходится нажимать «Показать ещё» девять раз. В бумажной записной книжке для этого есть алфавитные вырубки по краю страниц. Пользователь выбрал их вместе с оформлением «Ежедневник» (28 октября 2026). Если букву ещё не показали, список догружается до неё, как с новым контактом.

## What Changes

- По правому краю листа со списком — алфавитные вырубки: только буквы, на которые в списке есть люди, по алфавиту. На компьютере вырубки выступают за край листа на сукно, на телефоне — узкая полоска у края листа.
- Нажала букву — список прокручивается к ней, буква встаёт под строку поиска.
- Буква дальше показанной части — список догружается до неё целыми сотнями, как после «Показать ещё», и прокручивается к ней.
- Вырубки следуют за поиском и группой: при поиске — буквы найденных, в группе — буквы её людей.
- Переход по букве не добавляет шагов в историю браузера, как «Показать ещё». Длина списка остаётся в адресе: «Назад» из карточки возвращает на то же место.

Вне рамок:

- подсветка буквы, до которой докрутили;
- перетаскивание пальцем по полоске, как в телефонной книге;
- вырубки на странице «Группы» и в «Пора связаться».

## Capabilities

Нет.

### Modified Capabilities
