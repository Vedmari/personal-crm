# Tasks

Порядок в каждой задаче с тестами — TDD: написать тесты, запустить и увидеть их красными, написать код, увидеть зелёными. Название теста — название сценария из спеки. Тест, который сразу зелёный, переписать: он ничего не проверяет.

`.env` агент не читает и не пишет: когда нужна новая строка, говорит пользователю, какую добавить. Проверки интерфейса агентом — на временной базе `personal_crm_e2e`, рабочую базу `personal_crm` меняет только миграция из задачи 3.5 после показа SQL. Временную базу агент сам не удаляет.
