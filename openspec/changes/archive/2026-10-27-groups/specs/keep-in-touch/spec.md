# Spec Delta

## MODIFIED Requirements

### Requirement: Когда блока нет

Система SHALL не показывать блок «Пора связаться», если ни один контакт не просрочен, в строке поиска что-то набрано или на главном экране выбрана группа.

#### Scenario: Никто не просрочен

- **WHEN** ни у одного контакта срок связи не прошёл
- **THEN** блока нет, главный экран выглядит как раньше

#### Scenario: Идёт поиск

- **WHEN** в строке поиска набрано «анна»
- **THEN** блока нет, видны только результаты поиска
- **AND** после очистки поиска блок снова на месте

#### Scenario: Выбрана группа

- **WHEN** на главном экране выбрана группа «Теннис», а среди контактов есть просроченные
- **THEN** блока нет, виден только список группы
- **AND** после нажатия «Все» блок снова на месте
