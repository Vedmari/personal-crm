# Tasks

Порядок в каждой задаче с тестами — TDD: написать тесты, запустить `pnpm test` и увидеть их красными, написать код, увидеть зелёными. Название теста — название сценария из спеки. Тест, который сразу зелёный, переписать: он ничего не проверяет.

Проверки интерфейса агентом — на временной базе `personal_crm_e2e`, рабочую базу не трогаем. Временную базу агент сам не удаляет: в отчёте называет её и даёт команду удаления. Тестовую базу `…_test` тесты оставляют на месте и только очищают в ней таблицы.
